## 0.1.0 (2026-10-23)

### 🚀 New Features

- Start and stop Serverpod servers from the Run controls, with hot reload on Serverpod 4.
- Debug servers with breakpoints, conditions, logpoints, stepping, variables, and evaluation.
- Generate code when a model or endpoint file is saved.
- Create migrations and repair migrations, and apply pending migrations.
- Check model files with the Serverpod language server.
- Run the scripts of a server's `pubspec.yaml`.
- Start and stop Docker services, create projects, and upgrade the CLI.
